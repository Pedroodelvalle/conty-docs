A Conty precisa saber o que cada creator gerou: quem vendeu, quanto, e se a venda foi cancelada depois. Esse dado chega por um de dois caminhos.

<CardGroup cols={2}>
  <Card title="Com conectores" icon="plug">
    **Sem código.** Você liga a conta da loja, do meio de pagamento ou do analytics no painel da Conty, em **Plugins → Conectores**. A Conty lê os pedidos e as cobranças sozinha.
  </Card>
  <Card title="Com a API" icon="code">
    **O seu sistema manda para a Conty.** Use quando a venda acontece num checkout próprio ou numa plataforma que ainda não tem conector. Você chama a API a cada venda ou evento.
  </Card>
</CardGroup>

Na dúvida, comece pelo conector: se a sua plataforma tem um, ele resolve sem programar. A API fica para o que o conector não cobre.

## Qual é o seu caso

| Seu caso | Caminho | Guia |
|---|---|---|
| Loja na Shopify | Conector | [Shopify](/api/guias/conectores/shopify) |
| Loja na Nuvemshop | Conector | [Nuvemshop](/api/guias/conectores/nuvemshop) |
| Assinatura dentro do app (App Store e Google Play) com RevenueCat | Conector | [RevenueCat](/api/guias/conectores/revenuecat) |
| Cobrança ou assinatura no site cobrada pelo Asaas | Conector | [Asaas](/api/guias/conectores/asaas) |
| Impulsionar os vídeos dos creators como anúncio no Instagram | Conector | [Meta Ads](/api/guias/conectores/meta-ads) |
| Visitas e eventos do site que já estão no Google Analytics 4 ou no PostHog | Conector | [Google Analytics 4](/api/guias/conectores/google-analytics) ou [PostHog](/api/guias/conectores/posthog) |
| Downloads do app na App Store | Conector | [App Store Connect](/api/guias/conectores/app-store-connect) |
| Checkout próprio, Stripe ou outra plataforma, com comissão por venda | API | [Registrar vendas pela API](/api/guias/registrar-vendas) |
| Assinatura no Stripe ou em checkout próprio, com comissão por cobrança | API | [Assinatura sem conector](/api/guias/assinatura-sem-conector) |
| Cadastros, compras e outros eventos do site ou do app, sem comissão | API (SDK) | [Eventos de conversão](/api/guias/eventos-de-conversao) |
| Ler as campanhas e os creators no seu sistema | API | [Acompanhar o quadro](/api/guias/acompanhar-quadro) |

<Note>
  **Venda tem comissão, evento não.** Venda (pelo conector de loja, de assinatura ou pela API de vendas) entra no cupom do creator e gera comissão. Evento (pelo SDK, pelo Google Analytics ou pelo PostHog) aparece em **Tráfego**, nos resultados da campanha, e serve para medir.
</Note>
