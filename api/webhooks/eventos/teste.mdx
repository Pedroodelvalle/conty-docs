Todo evento usa o [envelope comum](/api/webhooks/visao-geral). O que muda de um para outro é o `type`, o `summary` e os blocos extras dentro de `data`.

Sai só quando você clica em **Enviar teste** no painel. Nenhum endpoint assina este tipo: ele chega mesmo que o endpoint não tenha marcado nada. Os dados de campanha, creator e missão são fictícios.

```json
{
  "id": "9f8e7d6c-5b4a-4f3e-8d2c-1b0a9f8e7d6c",
  "type": "webhook.test",
  "created_at": "2026-10-21T12:58:00.004Z",
  "tenant": "conty",
  "summary": "Teste do webhook da Conty: se esta mensagem chegou, o endpoint está configurado.",
  "data": {
    "brand": { "id": "5e4d3c2b-1a0f-4e9d-8c7b-6a5f4e3d2c1b", "name": "BeConfident" },
    "campaign": { "id": "00000000-0000-4000-8000-000000000001", "name": "Campanha de teste", "url": null },
    "creator": { "id": "00000000-0000-4000-8000-000000000002", "name": "Creator de teste", "handle": "@creator.teste" },
    "mission": { "id": "00000000-0000-4000-8000-000000000003", "status": "em_analise", "platform": "instagram" },
    "submission": { "items": ["video"], "resubmission": false, "format": "video" }
  }
}
```
